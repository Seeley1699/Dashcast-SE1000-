### 查看历史

```powershell
& $git -C $D log --oneline
```

### 回滚到某个提交

```powershell
# 先看历史找到 commit id
& $git -C $D log --oneline

# 硬回滚（丢弃所有未提交改动）
& $git -C $D reset --hard <commit-id>
```

### 撤销单文件改动

```powershell
& $git -C $D checkout -- src/ap/app/src/main/java/com/hermes/dashcast/MainActivity.java
```

## 提交前自动备份（可选）

在 PowerShell 里加一个函数，每次编辑前自动提交：

```powershell
function Save-Dashcast {
    param([string]$msg = "checkpoint $(Get-Date -Format 'HH:mm:ss')")
    $git='C:\Program Files\Git\cmd\git.exe'
    $D='E:\Program Files\DSH\dashcast'
    & $git -C $D add -A
    & $git -C $D commit -m $msg
    & $git -C $D log --oneline -1
}
```

用法：
```powershell
Save-Dashcast "改遮罩面板前"
```

## .gitignore 排除了什么

| 排除项 | 原因 |
|---|---|
| `src/ap/.gradle/`、`build/` | Gradle 构建缓存，可重新生成 |
| `artifacts/*.apk`、`dashcastd`、`dcapd2` | 二进制体积大、每次构建都变；靠 `artifacts/MD5SUMS.txt` 记录版本 |
| `jadx/`、`decompiled/` | 反编译工具与产物 |
| `*.log` | 临时日志 |

**注意**：`artifacts/MD5SUMS.txt` 是入库的，它记录了当前产物版本。发布新版本时记得一起更新。

### 2. 编译 dashcastd（仪表接收器）


### 4. 更新 assets（改过 dcapd2 后必须做）

```powershell
$H='E:\Program Files\DSH\dashcast'
$W="$H\build_out"
$A="$H\src\ap\app\src\main\assets"

# 更新 dcapd2
$b=[IO.File]::ReadAllBytes("$W\dcapd2")
[IO.File]::WriteAllText("$A\dcapd2.b64", [Convert]::ToBase64String($b,[Base64FormattingOptions]::None))
$md=([Security.Cryptography.MD5]::Create().ComputeHash($b)|%{$_.ToString('x2')}) -join ''

# 更新源码里的 BIN_MD5 常量
$p="$H\src\ap\app\src\main\java\com\hermes\dashcast\MirrorController.java"
$t=[IO.File]::ReadAllText($p)
$t=[regex]::Replace($t,'String BIN_MD5 = "[a-f0-9]{32}";',"String BIN_MD5 = `"$md`";")
[IO.File]::WriteAllText($p,$t,(New-Object System.Text.UTF8Encoding($false)))
```

**关键**：改了 `dcapd2.c` 一定要同步更新 assets 和 `BIN_MD5`，否则 App 会把旧版本当"已是最新"跳过推送。

## CP 恢复原厂（重要）

投屏结束后，CP 必须回到"重启前的样子"。App 的【停止投屏】会自动做，但有时需要手动兜底：

```powershell
function CpExec($cmd){
    $adb='C:\Users\94790\AppData\Local\Android\Sdk\platform-tools\adb.exe'
    $bb=[Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes($cmd))
    & $adb shell "rm -f /data/user/11/com.hermes.dashcast/files/cpcmd.out" | Out-Null
    & $adb shell "am broadcast -n com.hermes.dashcast/.DiagReceiver -a com.hermes.dashcast.CPCMD --es cmd b64:$bb" | Out-Null
    $res=''
    for($n=0;$n -lt 60;$n++){
        Start-Sleep -Milliseconds 100
        $res = & $adb shell "cat /data/user/11/com.hermes.dashcast/files/cpcmd.out 2>/dev/null" | Out-String
        if($res -match '--- output ---'){ break }
    }
    return $res
}

CpExec("pkill -9 dashcastd 2>/dev/null; sleep 1; " +
       "rm -f /run/dashcastd /run/dashcastd.log; " +
       "export XDG_RUNTIME_DIR=/etc/weston/weston_xdg_runtime_dir; " +
       "export WAYLAND_DISPLAY=wayland-1; " +
       "LayerManagerControl destroy layer 99 2>/dev/null; " +
       "LayerManagerControl set screen 0 render order 10 2>/dev/null; " +
       "echo CLEAN")
```

核验：
```
[进程] NO_PROC
[文件] NO_FILE
[图层] The layer with id: 99 does not exist
[渲染序] 10
```
